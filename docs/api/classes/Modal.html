Class Modal

An accessible modal dialog component following WAI-ARIA patterns.

Traps focus inside the modal when open, locks body scroll, and restores focus to the trigger element on close. Supports an optional backdrop that closes the modal on click.

Example

const modal = new Modal({
  trigger: document.getElementById('modal-trigger'),
  modal: document.getElementById('modal-panel'),
  backdrop: document.getElementById('modal-backdrop'),
});
