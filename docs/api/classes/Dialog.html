Class Dialog

An accessible non-modal dialog component.

Unlike Modal, this dialog does NOT trap focus, allowing users to tab out naturally. Uses the focus stack to restore focus on close. Follows the WAI-ARIA dialog pattern with aria-modal="false".

Example

const dialog = new Dialog({
  trigger: document.getElementById('dialog-trigger'),
  dialog: document.getElementById('dialog-panel'),
});
