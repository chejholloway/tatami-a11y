Class Accordion

An accessible accordion component following the WAI-ARIA accordion pattern.

Manages a set of expandable sections where each section consists of a header button and its associated content panel. Supports single and multiple panel modes, keyboard navigation (Arrow keys, Home, End, Enter, Space), and announces expand/collapse states to assistive technology.

Example

const accordion = new Accordion({
  container: document.getElementById('my-accordion'),
  allowMultiple: false,
});
