Class ReorderableList

An accessible reorderable list that supports keyboard and drag-and-drop reordering.

Keyboard reordering uses Ctrl+ArrowUp/Down (or Ctrl+Home/End) to move items. When drag-and-drop is enabled, items are made draggable and a visual drop indicator is shown during drag operations. Screen reader announcements provide feedback on reorder actions.

Example

const list = new ReorderableList({
  list: document.getElementById('my-list'),
  dragAndDrop: true,
});
