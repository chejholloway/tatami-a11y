    Interface RovingTabindexOptions

    Roving tabindex navigation primitive.

    Manages the WAI-ARIA roving tabindex pattern for lists and grids: exactly one child has tabindex="0", all others have tabindex="-1". Arrow keys move focus between items.

    Supports:

    • Vertical lists (ArrowUp/ArrowDown)
    • Horizontal lists (ArrowLeft/ArrowRight)
    • Grids (ArrowUp/Down moves by column count, ArrowLeft/Right by 1)
    • Home/End navigation
    • Custom key overrides via beforeKey callback
    • Dynamic item list changes via refresh()
    interface RovingTabindexOptions {
        beforeKey?: (e: KeyboardEvent, activeIndex: number) => boolean;
        columns?: number;
        container: HTMLElement;
        onActiveChange?: (index: number, element: HTMLElement) => void;
        orientation?: "vertical" | "horizontal" | "both";
        selector: string;
        wrap?: boolean;
    }

    beforeKey?: (e: KeyboardEvent, activeIndex: number) => boolean

    Called before each key is handled. Return true to prevent default handling (the component handles it instead). Receives the original event and the current active index.

    Optionalcolumns

    columns?: number

    onActiveChange?: (index: number, element: HTMLElement) => void
